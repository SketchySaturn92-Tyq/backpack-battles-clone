# 背包乱斗·复刻版 顶层设计

> 参考作品：Backpack Battles（背包乱斗：福西法的宝藏），Steam AppID 2427700
> 开发方：PlayWithFurcifer / 发行：IndieArk、Shochiku
> 定位：紧张刺激的背包管理 PvP 自走棋
> 本项目目标：用浏览器可运行的最小闭环，复刻其核心乐趣，作为可持续迭代的自研版本

## 1. 一句话定位

把「空间摆放」变成资源。玩家在有限格子里塞进形状各异的道具，让相邻关系产生增益，
再用这套构筑和对手的构筑自动打一架，输的人掉血。

## 2. 原作要素拆解

| 要素 | 原作表现 | 本复刻版的取舍 |
| --- | --- | --- |
| 背包 | 网格容器，道具形状占格 | 保留，网格 + 多格形状 |
| 道具 | 形状、大小、稀有度、价格各异，超 500 种 | 精简到 30+ 种，覆盖 5 大类 |
| 摆放 | 位置与相邻关系决定强度 | 保留：相邻加成、同类协同、朝向 |
| 合成 | 低阶道具合成神器（如两把小刀合成双刀） | 保留：同名同阶叠加合成 |
| 商店 | 金币购买、刷新、锁定 | 保留：金币 + 刷新 + 锁定 |
| 职业 | 七大职业五大子职业 | 先做 1 个职业，预留扩展位 |
| 对战 | 与其他玩家的构筑自动对战 | 保留：确定性自动战斗 + AI 构筑池 |
| 死亡淘汰 | 血量归零淘汰，排名与积分 | 保留：血量 + 胜场 + 排名结算 |
| 模式 | 休闲 / 排名 / 自定义 / 大厅 | 仅做单机休闲（无限时），其余留接口 |

## 3. 核心循环

1. 准备阶段：拿金币 → 逛商店 → 买道具 → 拖进背包 → 调整摆放 → 合成升级。
2. 战斗阶段：双方道具按顺序自动触发，打完出结果。
3. 结算阶段：败者掉血、双方涨金币、回合数 +1，商店刷新一轮。
4. 终局：血量归零淘汰；撑到指定胜场或指定回合则判为吃鸡。

## 4. 玩法设计原则

- 空间即资源：格子有限，形状与朝向决定能塞多少、能不能连锁。
- 组合大于数值：相邻协同、同类词条、合成升级，三条路子都要能赢。
- 信息全透明：对手构筑可见（或战斗中逐格揭示），输要输得明白。
- 战斗可复盘：逐条战斗日志 + 时间轴，能看清是哪一件道具翻的盘。
- 无隐藏随机：商店随机但可控（刷新/锁定），战斗尽量确定性。

## 5. 简化版范围（v0.1）

必做：
- 单职业「游侠」；6×7 背包网格。
- 商店 5 格、刷新、锁定、升级（提升稀有度与格数）。
- 道具 30+ 件，5 大类：武器 / 防具 / 食物药剂 / 宝石 / 饰品。
- 摆放交互：拖拽、旋转、非法位置高亮、拿起放下。
- 相邻与协同：武器相邻加攻速、宝石相邻加属性、同类叠加。
- 合成：同名同阶两件合成一件高阶。
- 战斗：块、伤害、治疗、中毒、回复、暴击、攻速六条基础机制。
- AI 对手：按回合强度递增的构筑池，逐回合变强。
- 回合制比赛：血量、金币、胜场、淘汰、胜利条件。
- 战斗日志与结算面板。

暂不做（写进路线图）：
- 联机与真人匹配、排名积分、成就、Steam 云。
- 多职业与子职业、500 件道具全量。
- 音效音乐、手柄、本地化。

## 6. 体验目标

- 3 分钟内学会：第一局不看说明也能买、能放、能打。
- 20 分钟一局：单局 12~16 回合，能吃鸡也能死得有节奏。
- 每次失败可归因：日志能指出关键道具与关键回合。

## 7. 技术选型

- 纯前端：HTML + CSS + 原生 ES Module，零构建、零依赖，双击即玩。
- 数据驱动：道具、构筑池、平衡数值全部走数据表，改数值不动逻辑。
- 确定性战斗：以种子驱动的伪随机，保证同一份构筑同一结果，便于回归测试。
- 分层：数据层 / 规则层 / 战斗层 / 渲染层 / 流程层，单文件单职责。

## 8. 目录结构

```
backpack-battles-clone/
├─ index.html              入口页面
├─ src/
│  ├─ css/style.css        样式
│  └─ js/
│     ├─ data/*.js         道具表、构筑池、常量
│     ├─ core/*.js         网格、商店、战斗、流程
│     ├─ ui/*.js           渲染与拖拽交互
│     └─ main.js           装配与启动
├─ assets/icons/           美术资源（Meowa 生成）
├─ docs/                   设计与文档
├─ tools/                  校验与测试脚本
└─ CHANGELOG.md            更新日志
```

## 9. 版本路线

- v0.1 可玩闭环：网格 + 商店 + 战斗 + AI（当前）
- v0.2 深度：更多道具与词条、稳定型/毒系流派、合成树。
- v0.3 内容：第二、第三职业，子职业分支。
- v0.4 表现：美术升级（Meowa 出图 + 动画）、音效、战斗特效。
- v0.5 在线：真人匹配、排名、分享构筑码。
