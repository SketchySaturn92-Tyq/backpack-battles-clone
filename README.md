# 背包乱斗 · 复刻版

浏览器里直接玩的背包管理 PvP 自走棋，参考 Backpack Battles（背包乱斗：福西法的宝藏）。

**核心是整理**：舞台是固定的 9（横）×7（竖）网格，本身完全透明，只用一圈极淡虚线标范围。
真正能用的是你铺在上面的那块布 —— 只有布盖住的格子能放装备。布还能整体挪动、水平翻转、
顺时针旋转。怎么塞、谁先出手、谁和谁相邻，全都是你自己的决策。

## 这一版重做了什么

上一版把背包当成一整块固定网格，格子尺寸还会随窗口高度自适应：窗口一变格子就缩，
道具跟着漂移，手感很差。v0.7 把背包拆成「舞台 + 布」两层，并重做了整理页：

1. **舞台 + 布（核心改动）** —— 舞台固定 9（横）×7（竖），完全透明。只有被布盖住的
   格子能放装备，布外一律放不下。布可以整体上下左右挪（布上的道具跟着走），也可以
   水平翻转、顺时针旋转；变换后放不下的道具自动折成金币退回，不会凭空消失。
2. **在被子上往外扩** —— 开局自带「小背包布」，5×4 共 20 格，居中铺好。
   商店按方向卖扩容：花金币往上下左右各加一排，只加格子、不动原有格局，
   所以已经摆好的道具位置不会被打乱；越扩越贵，最多铺满整个 9×7 舞台。
3. **商店道具可以直接拖进背包** —— 从商店卡片按住往背包拖，跟随光标出现半透明图标，
   落点实时高亮可放/不可放，松手即买下并落在你指的格；只是点一下仍是老行为（自动找位）。
4. **不限容量的储物箱** —— 整理页中间多了一个储物箱，放在里面不占背包、也不参与战斗。
   背包道具拖进去即收好，点箱子里的道具一键取回背包。
5. **手感与布局** —— 格子锁死 64px，不随窗口缩放，顺带修掉「背包会自己移动」；
   主界面三列按 6:4 分：背包占六成（保证 9×64 的舞台完整放得下），
   中间是贴底的小储物方块，商店占剩下四成。事件栏已下线。
7. **立绘贴格** —— 图上按 contain 完整显示（不放大、不裁切），再用多层遮罩只保留
   占格对应的区域，所以既不会被格子切断，也不会盖到邻格的道具上。
   横放时切换成真正的横版立绘（assets/icons/rot/），不是把竖图压扁。
6. **选角色页重做** —— 立绘放大到 236px，每个角色一个小符号，点符号直接换人；
   页面正中是横跨整页的「开始游戏」按钮。

更早的 v0.2 打下的地基仍在：不规则形状系统、6 职业 × 12 分支、15 条组合联动、
16 条合成配方、事件流驱动的战斗演出。

## 怎么玩

- **挪布/变布**：背包面板下缘的 ↑ ↓ ← → 挪动布，⇋ 水平翻转，⟳ 顺时针旋转
- **扩布**：商店下方的「背包布」区选方向点一下，花金币加一排
- **买道具**：商店卡片按住往背包拖动，落点变绿就能放，松手即买下并落位；
  只点一下则自动落在第一个能放的位置
- **储物箱**：把背包里的道具拖进箱子；点箱子里的道具一键取回背包（自动找空位）
- **拖动道具**调整位置，落点实时提示能不能放（绿可放 / 红不可放）
- 选中道具后按 **R 旋转**（Shift+R 反向），按 **Delete 卖出**
- 用 **[ ]** 循环选中背包里的道具
- 点「自动整理」可以一键按类别聚拢，但不如手工精算

四条核心规则：

- **触发顺序**：从上到下、从左到右。关键武器往左上角摆。
- **相邻生效**：宝石只给相邻道具加成，塞在武器旁边才有用。
- **组合联动**：同类道具攒够件数触发额外效果（火焰系 3 件 +20% 伤害，
  锋刃 5 件继续提暴击与攻速…）。按件数算，所以小件更容易凑齐。
- **合成**：两件同名同阶道具**相邻**会自动合成，形状会变，通常需要重新整理。

目标：先拿 10 胜，或撑满 16 回合不掉光血。第 4 回合开放两个子职业分支。

## 背包布与扩张

开局固定自带「小背包布」（5×4，20 格），居中铺在 9×7 的透明舞台上。

扩容不是换布，而是在这块布上往外加一排：

| 方向 | 效果 | 价格 |
| --- | --- | --- |
| ← ↑ ↓ → | 往该方向加一排，长度和当前布对齐；顶到舞台边界会被拒 | 首排 6 金，之后每排 +2 |

- 扩张只加格子，**不改动原有格局**，已摆好的道具位置完全不变
- 扩张出来的格子和主体布一样能放东西
- 布整体挪动时，扩张出来的格子跟着一起走
- 布可以水平翻转、顺时针旋转；翻转旋转后越界的扩张格子会自动失效

布外一律放不下东西。任何操作都不会让道具凭空消失 —— 放不下的会折成半价金币退回。

## 地上有什么

- 45 件道具，18 件是不规则形状（有凹角、能互相嵌套），单件最多 8 格，

- 战斗机制：伤害、暴击、护甲、反伤、点燃、中毒，另有冰霜减速、吸血、破甲
- 事件流驱动的战斗演出 + 逐条日志 + 结算统计

## 本地运行

页面用的是原生 ES Module，`file://` 打开会被浏览器拦下，起个静态服务：

```
node tools/serve.mjs . 8848
```

或者：

```
python3 -m http.server 8848
```

然后访问 http://localhost:8848 。

## 技术选择

纯前端，HTML + CSS + 原生 ES Module，零构建零依赖。
分层严格：data 不依赖任何东西，core 不碰 DOM，ui 只读状态 ——
所以核心逻辑能在 node 里裸跑测试。

战斗产出**事件流**而不是文本，表现层照着事件播动画。想换表现不用动战斗代码。

## 美术

道具图标与角色立绘都用 Meowa 生成，64px 像素风。生成脚本 `tools/gen_art.sh`
与 `tools/gen_art_v2.sh`，映射脚本 `tools/assign_icons.py`，对照图工具 `tools/contact_sheet.py`。

出图前先读 `tools/art_spec.md`：Meowa 只出 1:1 画布，物体自身的长宽靠提示词控制，
提示词必须写清「方向 + 占画面宽度比例 + 上下顶边」三件事。
出图后用 `python3 tools/fit_art.py` 核对（加 `--write` 把画布归一化到占格比例），
它会把比例仍然偏宽、必须重出的图单独列出来。
