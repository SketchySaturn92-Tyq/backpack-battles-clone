# 背包乱斗 · 复刻版

浏览器里直接玩的背包管理 PvP 自走棋，参考 Backpack Battles（背包乱斗：福西法的宝藏）。

在 6×7 的背包里塞进形状各异的道具，让相邻关系产生增益，再跟对手的构筑自动打一场。

## 在线游玩

https://artifact.catsco.cc/backpack-battles/

同一份内容的备用域名：https://artifact.catsco.cn/backpack-battles/

## 本地运行

双击 index.html 就能开。或者起个静态服务：

```
python3 -m http.server 8848
```

然后打开 http://localhost:8848

操作：

- 左键商店卡片购买，右键或 Shift+左键锁定不被刷新
- 拖动道具进背包，绿色能放，红色放不下
- 选中道具后按 R 旋转，按 Delete 卖出
- 两件同名同阶道具相邻会自动合成高阶版本
- 宝石给相邻道具加成，同类武器挨在一起提速，最多三层
- 先拿 10 胜，或撑满 16 回合不掉光血

## 现在有什么

- 6×7 背包网格，多格形状道具，旋转与拖拽摆放
- 33 件道具，分武器 / 防具 / 食物 / 宝石 / 饰品五类
- 商店 5 格、刷新、锁定、四级升级，阶位权重随等级变化
- 相邻增益：宝石光环、同类武器提速
- 合成系统：4 条配方，支持连锁合成
- 确定性自动战斗：伤害、暴击、护甲、反伤、点燃、回复六种机制
- 16 个递进对手，五种流派，强度随回合上升
- 逐条战斗日志、强度对比、结算评分
- 完整单局流程：血量、金币、连胜奖励、淘汰与吃鸡

## 怎么验证

```
npm test
```

跑核心逻辑自检，59 项，覆盖数据表、网格、商店、战斗、对手池、单局流程和 60 局平衡抽样。

```
node tools/browser-check.mjs
```

起无头浏览器真跑一遍：加载页面、买道具、拖拽、旋转、开战、推进回合、打到结束，全程抓 JS 报错并截图。截图落在 art/verify/。

## 项目结构

```
index.html              入口
src/css/style.css       样式
src/js/data/            道具表、常量
src/js/core/            网格、商店、战斗、对手池、单局流程
src/js/ui/              渲染与样式映射
src/js/main.js          装配与事件
assets/icons/           道具图标（Meowa 生成）
docs/                   顶层设计、底层逻辑、更新日志
tools/                  自检、浏览器验收、美术生成与映射
art/                    美术中间产物与验收截图（不入库）
```

## 技术选择

纯前端，HTML + CSS + 原生 ES Module，零构建零依赖。数据驱动的道具表与平衡数值，确定性战斗用种子随机，核心逻辑不碰 DOM，所以能在 node 里裸跑测试。

## 美术

道具图标用 Meowa 生成，64px 像素风格，透明底。生成脚本 tools/gen_art.sh，映射脚本 tools/assign_icons.py。
