# 背包乱斗 · 复刻版

浏览器里直接玩的背包管理 PvP 自走棋，参考 Backpack Battles（背包乱斗：福西法的宝藏）。

**核心是整理**：道具是各种不规则形状，背包格子有限。怎么塞、谁先出手、谁和谁相邻，
全都是你自己的决策。

## 这一版重做了什么

上一版虽然叫背包乱斗，实际是数值自走棋：形状基本是矩形，买到手自动落位，
没有角色也没有职业，战斗只有文字日志。**占格只是容量限制，不是玩法。**

v0.2 把四件事补上：

1. **形状真的不规则** —— L 形、T 形、十字、镂空都有。战斧占 4 格但外接 2×3，
   它的凹角刚好能再塞一把 1×2 的匕首；巨剑是十字形占 6 格。
2. **位置有后果** —— 道具按从上到下、从左到右出手，越靠前起手越早。
   关键武器摆左上角还是右下角，战斗结果不一样（有测试断言）。
3. **六个职业与分支** —— 职业决定背包尺寸与被动（法师 5×8 最难塞，商人 7×8 最宽松），
   第 4 回合开放两个子职业分支。
4. **战斗有演出** —— 角色立绘、血条护甲条、斩击/箭矢/火焰/治疗/冰霜特效、
   暴击震动与飘字，全部按战斗事件流驱动。

## 怎么玩

- 左键商店卡片购买，右键或 Shift+左键锁定不被刷新
- **拖动道具**调整位置，落点实时提示能不能放（绿可放 / 红不可放）
- 按住拖动时形状会跟着鼠标走，松手落位
- 选中道具后按 **R 旋转**（Shift+R 反向），按 **Delete 卖出**
- 用 **[ ]** 循环选中背包里的道具
- 点「自动整理」可以一键按类别聚拢，但不如手工精算

四条核心规则：

- **触发顺序**：从上到下、从左到右。关键武器往左上角摆。
- **相邻生效**：宝石只给相邻道具加成，塞在武器旁边才有用。
- **组合联动**：同类道具攒够数量触发额外效果（3 件火焰系 +20% 伤害，
  5 件锋刃加暴击与攻速…）。按件数算，所以小件更容易凑齐。
- **合成**：两件同名同阶道具**相邻**会自动合成，形状会变，通常需要重新整理。

目标：先拿 10 胜，或撑满 16 回合不掉光血。

## 地上有什么

- 45 件道具，全部不规则形状，最多 8 格，五类四阶
- 6 职业 × 2 分支 = 12 种开局
- 15 条组合联动（火焰连击、万刃风暴、不落之城、永冻、箭雨…）
- 16 条合成配方，支持连锁
- 16 个递进对手，五种流派，也遵守同样的网格规则
- 战斗六种机制：伤害、暴击、护甲、反伤、点燃、中毒，另有冰霜、吸血、破甲
- 事件流驱动的战斗演出 + 逐条日志 + 结算统计

## 技术选择

纯前端，HTML + CSS + 原生 ES Module，零构建零依赖。
分层严格：data 不依赖任何东西，core 不碰 DOM，ui 只读状态 ——
所以核心逻辑能在 node 里裸跑测试。

战斗产出**事件流**而不是文本，表现层照着事件播动画。想换表现不用动战斗代码。

## 美术

道具图标与角色立绘都用 Meowa 生成，64px 像素风。生成脚本 `tools/gen_art.sh`
与 `tools/gen_art_v2.sh`，映射脚本 `tools/assign_icons.py`，对照图工具 `tools/contact_sheet.py`。
