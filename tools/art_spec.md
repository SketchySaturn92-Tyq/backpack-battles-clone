# 道具立绘出图规范

这份规范是给「以后再用 Meowa 出道具图」用的。它解决的是一个反复出现过的问题：
**图出来了，但放进背包里显得比格子小。**

## 为什么会显得小

道具在背包里用 `object-fit: contain` 渲染——图要完整塞进占格框，不能裁。

设立绘内容比例为 `ro`、占格外接比例为 `rs`：

| 情况 | 渲染结果 | 观感 |
| --- | --- | --- |
| `ro ≤ rs` | 高度方向填满占格 | 正好，两侧留一点空隙也不难看 |
| `ro > rs` | 宽度方向先撞到占格边界，高度撑不满 | **立绘比格子小，看起来像小图标配大方块** |

所以只有一种情况必须处理：**图画得比格子更「宽」**。
例：火焰法杖占格 1×4（`rs = 0.25`），如果画出来是个接近方形的法杖（`ro ≈ 1.0`），
它在 1×4 的长条里就只能用到四分之一高度。

## 两条硬规则

1. **出图前先定占格**：先想清楚这件道具占几格、外接框是几乘几，算出 `rs`
2. **提示词里写清物体自身的长宽**：要求「物体宽度只占画面宽度的 X」「高度顶到上下边缘」

Meowa 的 `pixel-gen-run` 只接受 1:1 画布（试过 1:2 / 2:1 / 1:3 都会 `Generation failed`），
所以**靠提示词控制物体在方形画布里的自身比例**，不要试图用 `--aspect-ratio` 控制。

## 提示词模板

把握住三件事：**方向、占比、留白**。

竖向道具（占格偏窄，如 1×3、1×4、2×5）：

```
...全部严格竖直摆放，画面里没有任何斜角、没有交叉、没有横向躺倒。
每件物体都很窄：宽度只占画面宽度的四分之一到三分之一，
高度从画面上边缘一直延伸到底部边缘，左右两侧各留大片透明空白。
```

横向道具（占格偏扁，如 3×1、4×1）：

```
...全部水平横向摆放，物体高度只占画面高度的一小半，左右顶到画面左右边缘。
```

方形道具（占格接近 1:1）：

```
...物体居中，长宽接近，上下左右都接近画面边缘，不要留大片空白。
```

失败经验：
- 只说「细长」不够，模型仍会给出接近方形的结果
- 只说「占满画面」会被理解成「铺满整张方形画布」，反而更方
- 必须同时说清「方向 + 宽度占比 + 上下/左右顶边」三件事，效果才稳定

## 出图后的两步校验

1. **量内容框**：`python3 tools/fit_art.py` 会逐件报出内容比、画布比与状态
2. **归一化画布**：`python3 tools/fit_art.py --write` 把画布比例改成占格比例
   （只补透明边、绝不裁掉物体），这样即使 `ro < rs` 也能保证画布比例是对的

判定标准：`内容比 ≤ 占格比 + 0.02` 且 `画布比 ≈ 占格比`。
不满足的那几件只能重出图——`fit_art.py` 会把它们单独列出来。
